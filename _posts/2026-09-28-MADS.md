## MS in Applied Data Science - September 2026:

In September 2026, I completed my first Linear Models group project, which was an IMRaD paper on the relationship between house prices and distance to rail trails from a consulting perspective. In this report, I ran a log-linear multiple regression model, did exploratory data analysis, made diagnostic plots, and wrote the conclusion. My partner and I implemented an Agile methodology and assigned work based on comparative advantage, since my partner was not as familiar with the concept of interaction terms. 

Additionally, I began working on my group project for Data Visualization and Professional Skills for Statisticians. This project is a presentation analyzing compensation in the Data Science/AI labor market for an imaginary search and recruitment firm. In the weeks leading up to this project, I’ve learned how to create a wide set of graphs in R, including histograms, scatterplots, contour plots, kernel density estimate plots, violin plots, grid or hexagonal heat maps, correlograms, pairs plots, and parallel coordinates plots. 

In Statistical Computing, I completed my first four labs. These involved the use of Git repositories to maintain version control by staging, committing, and syncing changes between my local machine and the remote server. I built Python programs in Visual Studios and applied the principles of good software design, like modularity and separation of concerns. Also, I learned to format my code cleanly so it could pass the flake8 autograder. In Lab 4, I used pytest to create unit tests on edge cases, random cases, and error cases and generated coverage reports after stress testing my programs. 

Finally, in Statistical Methods in Finance, I learned about each aspect of the Black-Scholes model. We covered the lognormal pricing model, nonparametric density estimation, the Ljung-Box test for autocorrelation, and volatility clustering models like ARCH, GARCH, and APARCH. In a Jupyter notebook, I ran a Shapiro-Wilk test and created kernel density estimate plots and Normal probability plots to assess the Normality of weekly log returns compared to monthly log returns for a chosen company. I also created an autocorrelation plot and ran an augmented Dickey-Fuller test to assess the stationarity daily log returns for a selected firm.
